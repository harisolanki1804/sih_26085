# Raw Moisture Data — Provenance Notice

This directory is intentionally left without raw source files because
the satellite moisture proxy (`../moisture_satellite/mumbai_satellite_moisture_proxy.json`)
is a **synthetically constructed dataset**, not a direct download from any satellite instrument.

## How the Moisture Proxy Was Derived

The proxy values (regional_soil_saturation_pct, atmospheric_cape_jkg, convective_cloud_top_temp_celsius,
regional_wind_speed_10m_ms) were computed as regional averages from the per-cell feature grid,
which itself was generated by `data_pipeline/dataset_downloader.py` using:

1. **Rainfall**: Mathematical model calibrated to IMD 0.25-deg gridded rainfall climatology for Mumbai.
2. **DEM/Elevation**: Open-Meteo SRTM Elevation API (real API query) or calibrated Mumbai terrain model.
3. **Soil Moisture**: Derived from rainfall accumulation + soil physics model.
4. **CAPE (Atmospheric Instability)**: Derived from convective model progression.
5. **Wind**: Monsoon westerly wind model with squall-phase enhancement.

## Data Provenance

- **Type**: Synthetic construct (not raw instrument data)
- **Purpose**: Prototype training and demo for VARUNA early warning system
- **Event Window**: 2022-07-05 to 2022-07-07 (3-day extreme monsoon event simulation)
- **Calibration**: Values calibrated to match real Mumbai terrain, flood hotspot locations,
  and known monsoon behavior patterns
